# Privacy Policy — Community Comment Search for SB Nation

Last updated: September 23, 2026

Community Comment Search for SB Nation is an unofficial browser extension that helps users search comment authors and text on supported SB Nation community articles. It is not affiliated with SB Nation.

## Information the extension handles

The extension reads visible comment usernames, comment text, reply structure, and comment identifiers on supported article pages. It uses that information in the current browser tab to build search results and navigate to comments. It also uses the current page's address and page markup to decide whether to display the search panel. Search terms are processed locally.

## Storage and sharing

The extension keeps its search index in the current tab's memory. It does not send comment content, search terms, or browsing history to the publisher or third parties, and it does not store them across browser sessions. The extension does not include analytics or advertising trackers.

## External support link

The search panel includes a small Ko-fi support button rendered from code included in the extension. It makes no request to Ko-fi when the panel appears. Clicking the button opens `https://ko-fi.com/H8M127JQ4U` in a new tab without sending the referring page URL. Ko-fi has its own privacy practices. The extension does not send comment content or search terms to Ko-fi.

## Changes and contact

If the extension's data practices change, this policy will be updated before the changed version is published. For questions, contact: bigbotsai.dev@gmail.com.
